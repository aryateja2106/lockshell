## Notes

- Stress mode uses Secure Enclave keys without biometric ACL.
  Labels `lockshell-stress-user` / `lockshell-stress-ca` are disjoint
  from production `lockshell-user` / `lockshell-ca`.
- The CA pubkey distributed to the containers is the stress CA;
  rerunning `lockshell ssh-init` (without stress mode) restores production CA.
- Each successful op is a full round-trip: cert mint → SSH dial →
  bash -s on remote → stdout redaction → audit row.
